# Evidence

One folder per test attempt, named `<yyyy-mm-dd>`, holding what was actually
observed: screenshots, copied System Check reports, logs.

This folder is empty because no clean-machine test has been run yet. That is
the honest state, and `CURRENT_STATUS.md` says so. Nothing is marked WORKING on
the strength of an untested step.

Never commit a real `.flp`, a render of someone's music, or a log containing an
API key. The System Check's Copy Report is already sanitized; raw logs are not
guaranteed to be.
